# Shecurity

A free personal safety app with your own safety circle: SOS with live location, share your plans, walk me home, check-ins, fake call and siren. No ads.

- Website: https://punselie15.github.io/shecurity/
- App: https://punselie15.github.io/shecurity/app/

## Structure
- `index.html`, `nl/`, `guides/`, `privacy.html`: the website
- `app/`: the app itself (a progressive web app, no build step)
- `backend/`: the Supabase database schema and the push notification function

Shecurity helps you reach people you trust. It does not replace emergency services.
